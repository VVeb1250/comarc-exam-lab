บท 1/6

ทุกคำสั่งใช้ร่วมกัน

Instruction Fetch

เป้าหมาย: อ่าน Instruction เข้ามา และเตรียม PC สำหรับคำสั่งถัดไป

Step 0: Fetch + PC Update

State 0 → Next State 1

สมมติ PC=1000 CPU ต้องอ่านคำสั่งจาก Memory Address 1000 มาเก็บไว้ใน IR พร้อมเพิ่ม PC เป็น 1004 เราแยกวงจรเป็นสองภาพเพื่อให้ดูแต่ละงานชัด แต่ทั้งคู่เกิดใน State 0 เดียวกัน

วงจรย่อจากรูปที่ 2 ของข้อสอบ

ทางที่ 1: อ่านคำสั่งจาก Memory

ทางที่ 2: คำนวณ PC + 4

DATA Operation

โจทย์ให้มาแล้ว

IR ← Mem[PC] ; PC ← PC + 4

ตัวอย่าง: IR ได้คำสั่ง / PC เปลี่ยน 1000 → 1004

CONTROL ของ Step นี้

1. เลือกทาง

IorD = 0

ALUSrcA = 0

ใช้ PC เข้า ALU

ALUSrcB = 01

ALUOp = 00

สั่งให้ ALU บวก

PCSource = 00

นำผล ALU โดยตรงไปที่ PC

2. เปิดใช้งาน

MemRead = 1

อ่าน Instruction จาก Memory

IRWrite = 1

เก็บ Instruction ลง IR

PCWrite = 1

อัปเดต PC เป็น 1004

IorD เลือกว่าที่อยู่มาจากไหน ส่วน MemRead เป็นตัวอนุญาตให้อ่านจริง

sw • Store Word

เป้าหมาย: sw $t0, 8($s1) → Mem[208] ← 42

Step 1/2: คำนวณ Address

State 1 → Next State 2

ต้องรู้ว่าจะเขียน Memory ช่องไหนก่อน จึงเอา Base Address จาก $s1 ซึ่งมีค่า 200 มาบวก Immediate 8 ผลลัพธ์ 208 ถูกเก็บใน ALUOut

วงจรย่อจากรูปที่ 2 ของข้อสอบ

Register + Sign-extended Immediate → ALUOut

DATA Operation

โจทย์ให้มาแล้ว

ALUOut ← Reg[IR[25:21]] + signext(IR[15:0])

ตัวอย่าง: ALUOut ← 200 + 8 = 208

CONTROL ของ Step นี้

1. เลือกทาง

ALUSrcA = 1

ALUSrcB = 10

ไม่มีสัญญาณที่ต้องเปิดเพิ่ม

ยังไม่เขียน Memory, Register File หรือ PC ผล ALU ถูกเก็บใน ALUOut ของวงจรตาม Clock

ยังไม่เขียน Memory เพราะ Step นี้ทำแค่คำนวณ Address

Step 2/2: เขียน Memory

State 2 → Next State 0

ตอนนี้ Address 208 พร้อมแล้ว เราส่ง ALUOut ไปที่ Address ของ Memory และส่งค่า 42 จาก Register $t0 เข้าช่อง Write data ก่อนเปิด MemWrite

วงจรย่อจากรูปที่ 2 ของข้อสอบ

ALUOut เป็น Address / Reg[rt] เป็น Write data

DATA Operation

ต้องเติมในตารางที่ 3

Mem[ALUOut] ← Reg[IR[20:16]]

ตัวอย่าง: Mem[208] ← 42

CONTROL ของ Step นี้

1. เลือกทาง

IorD = 1

ใช้ ALUOut เป็น Memory Address

2. เปิดใช้งาน

MemWrite = 1

อนุญาตให้ Memory เขียนค่า 42

ในตารางที่ 3 ช่องนี้ต้องเติมทั้ง DATA Operation และ CONTROL

บท 3/6

lw • Load Word

เป้าหมาย: lw $t0, 8($s1) → Reg[$t0] ← 42

Step 1/2: คำนวณ Address

State 1 → Next State 2

เหมือน sw เพราะยังต้องการ Address 200+8=208 ต่างกันที่ขั้นถัดไปเท่านั้น ข้อมูล 208 จะถูกเก็บไว้ใน ALUOut

วงจรย่อจากรูปที่ 2 ของข้อสอบ

ใช้เส้นทางคำนวณ Address เดียวกับ sw

DATA Operation

โจทย์ให้มาแล้ว

ALUOut ← Reg[IR[25:21]] + signext(IR[15:0])

ตัวอย่าง: ALUOut ← 208

CONTROL ของ Step นี้

1. เลือกทาง

ALUSrcA = 1

เลือก Register ตัวแรก

ALUSrcB = 10

เลือก Immediate ช่อง 2

ALUOp = 00

บวกเพื่อคำนวณ Address

2. เปิดใช้งาน

ไม่มีสัญญาณที่ต้องเปิดเพิ่ม

ยังไม่เขียน Memory, Register File หรือ PC ผล ALU ถูกเก็บใน ALUOut ของวงจรตาม Clock

lw กับ sw ใช้ชุด CONTROL เดียวกันใน Step 1

Step 2/2: อ่าน Memory และ Write Back

State 2 → Next State 0

จาก Address 208 CPU อ่านข้อมูลใน Memory สมมติได้ 42 จากนั้นส่งค่า 42 ผ่าน MemtoReg ไปช่อง Write data ของ Register File และเลือก Register rt เป็นปลายทาง

วงจรย่อจากรูปที่ 2 ของข้อสอบ

ALUOut → IorD → Memory → MemtoReg → Register

DATA Operation

โจทย์ให้มาแล้ว

บท 4/6

R-type • ALU Operation

เป้าหมาย: add $t0, $s1, $s2 → Reg[$t0] ← 12

Step 1/2: ALU คำนวณ

State 1 → Next State 2

สมมติ $s1=5 และ $s2=7 คำสั่ง add ต้องเอา Register ทั้งสองตัวเข้า ALU โดยไม่ใช้ Immediate และ R-type ใช้ฟิลด์ funct ของ Instruction เพื่อระบุ Operation จริง

วงจรย่อจากรูปที่ 2 ของข้อสอบ

Register ตัวแรกและตัวที่สอง → ALUOut

DATA Operation

โจทย์ให้มาแล้ว

ALUOut ← Reg[IR[25:21]] op Reg[IR[20:16]]

ตัวอย่าง: สำหรับ add: ALUOut ← 5 + 7 = 12

CONTROL ของ Step นี้

1. เลือกทาง

ALUSrcA = 1

ใช้ Register ตัวแรก

ALUSrcB = 00

ใช้ Register ตัวที่สอง

ALUOp = 10

2. เปิดใช้งาน

ไม่มีสัญญาณที่ต้องเปิดเพิ่ม

ยังไม่เขียน Memory, Register File หรือ PC ผล ALU ถูกเก็บใน ALUOut ของวงจรตาม Clock

ALUOp=10 ไม่ได้แปลว่าบวกเสมอ แต่ให้เลือก Operation จาก funct

Step 2/2: Write Back ไป rd

State 2 → Next State 0

ผล 12 อยู่ใน ALUOut แล้ว ต้องส่งผลนี้กลับไปเขียน Register ปลายทางของ R-type ซึ่งอยู่ในฟิลด์ rd ที่บิต IR[15:11]

วงจรย่อจากรูปที่ 2 ของข้อสอบ

ALUOut → MemtoReg → Register File

DATA Operation

โจทย์ให้มาแล้ว

Reg[IR[15:11]] ← ALUOut

ตัวอย่าง: Reg[$t0] ← 12

CONTROL ของ Step นี้

1. เลือกทาง

MemtoReg = 0

เลือกค่า ALUOut ไม่ใช่ Memory

RegDst = 1

เลือกฟิลด์ rd เป็นปลายทาง

2. เปิดใช้งาน

RegWrite = 1

บท 5/6

คำนวณ Branch Target แล้วตรวจเงื่อนไข

beq • Branch if Equal

เป้าหมาย: ถ้า Reg[rs] = Reg[rt] ให้ PC ← Branch Target

Step 1/2: เตรียม Branch Target

State 1 → Next State 2

สมมติหลัง Fetch ค่า PC=1004 และ Immediate=3 CPU ต้องสร้าง Target จาก 1004 + (3×4) = 1016 ก่อน โดยยังไม่เปลี่ยน PC ไปตำแหน่งนี้

วงจรย่อจากรูปที่ 2 ของข้อสอบ

PC + (Immediate << 2) → ALUOut

DATA Operation

โจทย์ให้มาแล้ว

ALUOut ← PC + (signext(IR[15:0]) << 2)

ตัวอย่าง: ALUOut ← 1004 + 12 = 1016

CONTROL ของ Step นี้

1. เลือกทาง

ALUSrcA = 0

เลือก PC

ALUSrcB = 11

เลือก Immediate ที่ Shift left 2

ALUOp = 00

บวกเพื่อสร้าง Target

2. เปิดใช้งาน

ไม่มีสัญญาณที่ต้องเปิดเพิ่ม

ยังไม่เขียน Memory, Register File หรือ PC ผล ALU ถูกเก็บใน ALUOut ของวงจรตาม Clock

ยังไม่เปิด PCWrite เพราะต้องตรวจความเท่ากันก่อน

Step 2/2: ตรวจ Zero แล้ว Branch

State 2 → Next State 0

สมมติ Reg[rs]=7 และ Reg[rt]=7 เราสั่ง ALU ให้ลบ 7−7 ได้ Zero=1 จึงใช้ PCWriteCond อนุญาตให้ PC รับ Branch Target=1016 จาก ALUOut ของ Step 1

วงจรย่อจากรูปที่ 2 ของข้อสอบ

ALU ตรวจ Zero / ALUOut ส่ง Branch Target ไป PC

DATA Operation

โจทย์ให้มาแล้ว

if (A == B) PC ← ALUOut

ตัวอย่าง: 7 − 7 = 0 → Zero=1 → PC ← 1016

CONTROL ของ Step นี้

1. เลือกทาง

ALUSrcA = 1

เลือก Register ตัวแรก

ALUSrcB = 00

เลือก Register ตัวที่สอง

ALUOp = 01

ลบเพื่อตรวจว่าเท่ากัน

PCSource = 01

เลือก Branch Target จาก ALUOut

2. เปิดใช้งาน

PCWriteCond = 1

เขียน PC เฉพาะเมื่อ Zero=1

ผลลบของ ALU ใช้ตรวจ Zero ส่วน Address ที่จะ Branch มาจาก ALUOut ไม่ใช่ผลลบนั้น

บท 6/6

j • Jump

เป้าหมาย: PC ← Jump Address

Step 1/1: สร้าง Jump Address แล้วเขียน PC

State 1 → Next State 0

1. เลือกทาง

PCSource = 10

2. เปิดใช้งาน
