## สอนข้อ 3 ใหม่: อ่าน Datapath → เลือก MUX → Control Signals

เราจะใช้ข้อ 3 จาก FE2019b จริง โดยเริ่มจากศูนย์ ไม่สมมติว่าอ่านวงจรเป็นอยู่แล้ว เป้าหมายของบทนี้คือ เมื่อเห็นคำสั่ง `lw`, `sw`, `beq`, `j` หรือ R-type จะมองภาพแล้วรู้ได้ว่าข้อมูลต้องวิ่งผ่านอุปกรณ์ไหน MUX เลือกช่องอะไร และต้องเปิด Control Signal ตัวใด

### 1. ก่อนอื่น อ่านภาพ Datapath ให้ออก

นี่คือรูปที่ 2 จากข้อสอบ หน้า 4 ภาพดูยุ่งเพราะเส้นเชื่อมกันเยอะ แต่จริง ๆ เราไม่จำเป็นต้องอ่านทุกเส้นพร้อมกัน

แยกเป็น 2 ส่วนก่อน:

- **เส้นสีดำ = Data Path** เส้นทางที่ข้อมูลวิ่ง เช่น ตัวเลขจาก Register ไป ALU
- **เส้นสีส้ม = Control Signals** ตัวควบคุมว่าจะให้วงจรเลือกทางไหน อ่านหรือเขียนเมื่อไร

#### รู้จักอุปกรณ์สำคัญ 6 ตัว

<div className="table-scroll">

| อุปกรณ์ | ทำหน้าที่อะไร |
|---|---|
| PC | เก็บ Address ของคำสั่งที่จะอ่าน |
| Memory | เก็บ Instruction และ Data |
| Instruction Register (IR) | เก็บคำสั่งที่อ่านมา |
| Registers | อ่าน/เขียนค่าใน Register เช่น `$s0`, `$t0` |
| ALU | คำนวณบวก ลบ และ Logic รวมถึงคำนวณ Address |
| MUX | เลือกว่าจะให้ข้อมูลจากช่องไหนผ่านไป |

</div>

อุปกรณ์ที่สำคัญที่สุดสำหรับข้อนี้คือ MUX

### 2. MUX คืออะไร ทำไมต้องเลือก?

สมมติ ALU ต้องรับข้อมูล 2 ค่าเพื่อคำนวณ แต่ค่าที่ส่งเข้า ALU อาจมาจากหลายแหล่ง MUX จึงเลือกว่าจะแหล่งใดส่งต่อไป

ตัวอย่าง MUX 2 ช่อง:

<div className="table-scroll">

| Select | ข้อมูลที่เลือก |
|---|---|
| 0 | Register |
| 1 | Immediate |

</div>

ถ้าคำสั่งต้องใช้ค่าใน Register เราก็เลือก `0`; ถ้าต้องใช้ Immediate ก็เลือก `1`

**สำคัญ:** เลข `0` กับ `1` ไม่ได้มีความหมายตายตัวว่าเป็น Register หรือ Immediate ต้องดูว่าในภาพวงจรจริงช่องนั้นต่อมาจากไหน

### 3. อ่าน MUX ในภาพข้อสอบจริง

กลับไปที่รูปที่ 2 ให้มอง MUX สามตำแหน่งก่อน:

<div className="table-scroll">

| Control ของ MUX | ช่องที่เลือก | ข้อมูลที่ส่งต่อ |
|---|---:|---|
| `ALUSrcA` | `0` | `PC` |
| `ALUSrcA` | `1` | `Read data 1` จาก Register File |
| `ALUSrcB` | `00` | `Read data 2` จาก Register |
| `ALUSrcB` | `01` | ค่าคงที่ `4` |
| `ALUSrcB` | `10` | Sign-extended Immediate |
| `ALUSrcB` | `11` | Sign-extended Immediate ที่ Shift left 2 |
| `PCSource` | `00` | ALU result โดยตรง |
| `PCSource` | `01` | `ALUOut` (ผล ALU ที่เก็บไว้) |
| `PCSource` | `10` | Jump address |

</div>

สังเกตว่า `ALUSrcB = 10` หมายถึงช่อง 2 ไม่ใช่เลขสิบ เพราะ Control Signal นี้มีขนาด 2 บิต นี่คือข้อมูลพื้นฐานที่ต้องอ่านออกก่อนเริ่มโจทย์

### 4. ก่อนเลือก MUX ต้องอ่าน Instruction เป็น

ใน MIPS Instruction มีขนาด 32 บิต โดยตำแหน่งบิตบอกว่าจะใช้งาน Register ไหน และ Immediate อยู่ตรงไหน

ตัวอย่าง I-type: `sw $t0, 8($s1)`

<div className="table-scroll">

| Field | ขนาด | ความหมายในตัวอย่าง |
|---|---:|---|
| opcode | 6 bits | `sw` |
| rs | 5 bits | `$s1` |
| rt | 5 bits | `$t0` |
| immediate | 16 bits | `8` |

</div>

เรียงจากบิต 31 ทางซ้าย ไปบิต 0 ทางขวา

เวลามองรูป Datapath จะเจอ:

<div className="table-scroll">

| บิตจาก IR | ความหมาย |
|---|---|
| `[25:21]` | `rs`: Register ตัวแรก |
| `[20:16]` | `rt`: Register ตัวที่สอง |
| `[15:11]` | `rd`: Register ปลายทางของ R-type |
| `[15:0]` | Immediate |
| `[25:0]` | Jump target field |

</div>

ตัวอย่าง `sw $t0, 8($s1)` ให้แปลเป็นภาษาคนก่อน:

> เอาค่าที่เก็บใน `$t0` ไปเขียนลง Memory ณ Address ที่คำนวณจาก `$s1 + 8`

ถ้า `$s1 = 1000` และ `$t0 = 42` ผลที่ต้องเกิดคือ `Memory[1008] = 42` แค่นี้เราก็เริ่มรู้แล้วว่า ALU ต้องบวกอะไร และ Memory ต้องเขียนข้อมูลจากไหน

</section>

## บท 2/6: เขียนค่าจาก Register ลง Memory · `sw`

### `sw` • Store Word

**เป้าหมาย:** `sw $t0, 8($s1) → Mem[208] ← 42`

### Step 1/2: คำนวณ Address

**State 1 → Next State 2**

ต้องรู้ว่าจะเขียน Memory ช่องไหนก่อน จึงเอา Base Address จาก `$s1` ซึ่งมีค่า 200 มาบวก Immediate 8 ผลลัพธ์ 208 ถูกเก็บใน ALUOut

  <div className="mc-control-zones">
    <div><h4>1. เลือกทาง</h4><ul><li><code>IorD = 1</code> Memory ใช้ Address จาก ALUOut</li><li><code>MemtoReg = 1</code> เลือกข้อมูลจาก Memory</li><li><code>RegDst = 0</code> เลือก Register ปลายทาง rt</li></ul></div>
    <div><h4>2. เปิดใช้งาน</h4><ul><li><code>MemRead = 1</code> อ่านข้อมูลจาก Memory</li><li><code>RegWrite = 1</code> เขียนค่า 42 ลง Register</li></ul></div>
  </div>
  <p className="mc-step-note">MemtoReg เลือกข้อมูลที่จะเขียน ส่วน RegDst เลือก Register ที่จะรับข้อมูล</p>
  <div className="mc-step-footer">จบบท 3: lw • Load Word <span>บทถัดไป: R-type • ALU Operation</span></div>
</div>

</section>

<section className="lesson-section" id="ch3-rtype">

## บท 4/6: คำนวณด้วย Register สองตัว แล้ว Write Back

### R-type • ALU Operation

**เป้าหมาย:** `add $t0, $s1, $s2 → Reg[$t0] ← 12`

### Step 1/2: ALU คำนวณ

**State 1 → Next State 2**

สมมติ `$s1=5` และ `$s2=7` คำสั่ง `add` ต้องเอา Register ทั้งสองตัวเข้า ALU โดยไม่ใช้ Immediate และ R-type ใช้ฟิลด์ `funct` ของ Instruction เพื่อระบุ Operation จริง

<div className="mc-step-card">
  <div className="mc-step-heading"><strong>วงจรย่อจากรูปที่ 2 ของข้อสอบ</strong><span>Step 1/2 · State 1</span></div>
  <div className="mc-step-recap"><code>Register ตัวแรกและตัวที่สอง → ALUOut</code><span>Reg[rs] 5 · Reg[rt] 7 · SrcA 1 · SrcB 00 · ALU funct · ALUOut 12</span></div>
  <div className="mc-data-operation"><small>DATA Operation · โจทย์ให้มาแล้ว</small><code>ALUOut ← Reg[IR[25:21]] op Reg[IR[20:16]]</code><span>ตัวอย่าง: สำหรับ add, ALUOut ← 5 + 7 = 12</span></div>
  <div className="mc-control-zones">
    <div><h4>1. เลือกทาง</h4><ul><li><code>ALUSrcA = 1</code> ใช้ Register ตัวแรก</li><li><code>ALUSrcB = 00</code> ใช้ Register ตัวที่สอง</li><li><code>ALUOp = 10</code> ให้ ALU Control อ่าน funct</li></ul></div>
    <div><h4>2. เปิดใช้งาน</h4><p>ไม่มีสัญญาณที่ต้องเปิดเพิ่ม ยังไม่เขียน Memory, Register File หรือ PC ผล ALU ถูกเก็บใน ALUOut ของวงจรตาม Clock</p></div>
  </div>
  <p className="mc-step-note"><code>ALUOp=10</code> ไม่ได้แปลว่าบวกเสมอ แต่ให้เลือก Operation จาก funct</p>
  <div className="mc-step-footer">ผล: ALUOut = 12 <span>Next State 2</span></div>
</div>

### Step 2/2: Write Back ไป rd

**State 2 → Next State 0**

ผล 12 อยู่ใน ALUOut แล้ว ต้องส่งผลนี้กลับไปเขียน Register ปลายทางของ R-type ซึ่งอยู่ในฟิลด์ `rd` ที่บิต `IR[15:11]`

<div className="mc-step-card">
  <div className="mc-step-heading"><strong>วงจรย่อจากรูปที่ 2 ของข้อสอบ</strong><span>Step 2/2 · State 2</span></div>
  <div className="mc-step-recap"><code>ALUOut → MemtoReg → Register File</code><span>ALUOut 12 · Memory ไม่ใช้ · MemtoReg 0 · Write data 12 · RegDst=1 → rd · RegWrite=1</span></div>
  <div className="mc-data-operation"><small>DATA Operation · โจทย์ให้มาแล้ว</small><code>Reg[IR[15:11]] ← ALUOut</code><span>ตัวอย่าง: Reg[$t0] ← 12</span></div>
  <div className="mc-control-zones">
    <div><h4>1. เลือกทาง</h4><ul><li><code>MemtoReg = 0</code> เลือกค่า ALUOut ไม่ใช่ Memory</li><li><code>RegDst = 1</code> เลือกฟิลด์ rd เป็นปลายทาง</li></ul></div>
    <div><h4>2. เปิดใช้งาน</h4><ul><li><code>RegWrite = 1</code> อนุญาตเขียนผลลง Register</li></ul></div>
  </div>
  <p className="mc-step-note">R-type ใช้ rd (`RegDst=1`) แต่ lw ใช้ rt (`RegDst=0`)</p>
  <div className="mc-step-footer">จบบท 4: R-type • ALU Operation <span>บทถัดไป: beq • Branch if Equal</span></div>
</div>

</section>

<section className="lesson-section" id="ch3-beq">

## บท 5/6: คำนวณ Branch Target แล้วตรวจเงื่อนไข

### `beq` • Branch if Equal

**เป้าหมาย:** ถ้า `Reg[rs] = Reg[rt]` ให้ `PC ← Branch Target`

### Step 1/2: เตรียม Branch Target

**State 1 → Next State 2**

สมมติหลัง Fetch ค่า `PC=1004` และ Immediate=`3` CPU ต้องสร้าง Target จาก `1004 + (3×4) = 1016` ก่อน โดยยังไม่เปลี่ยน PC ไปตำแหน่งนี้

<div className="mc-step-card">
  <div className="mc-step-heading"><strong>วงจรย่อจากรูปที่ 2 ของข้อสอบ</strong><span>Step 1/2 · State 1</span></div>
  <div className="mc-step-recap"><code>PC + (Immediate &lt;&lt; 2) → ALUOut</code><span>PC 1004 · Imm &lt;&lt; 2 = 12 · SrcA 0 · SrcB 11 · ALU + · ALUOut 1016</span></div>
  <div className="mc-data-operation"><small>DATA Operation · โจทย์ให้มาแล้ว</small><code>ALUOut ← PC + (signext(IR[15:0]) &lt;&lt; 2)</code><span>ตัวอย่าง: ALUOut ← 1004 + 12 = 1016</span></div>
  <div className="mc-control-zones">
    <div><h4>1. เลือกทาง</h4><ul><li><code>ALUSrcA = 0</code> เลือก PC</li><li><code>ALUSrcB = 11</code> เลือก Immediate ที่ Shift left 2</li><li><code>ALUOp = 00</code> บวกเพื่อสร้าง Target</li></ul></div>
    <div><h4>2. เปิดใช้งาน</h4><p>ไม่มีสัญญาณที่ต้องเปิดเพิ่ม ยังไม่เขียน Memory, Register File หรือ PC ผล ALU ถูกเก็บใน ALUOut ของวงจรตาม Clock</p></div>
  </div>
  <p className="mc-step-note">ยังไม่เปิด PCWrite เพราะต้องตรวจความเท่ากันก่อน</p>
  <div className="mc-step-footer">ผล: ALUOut = 1016 <span>Next State 2</span></div>
</div>

### Step 2/2: ตรวจ Zero แล้ว Branch

**State 2 → Next State 0**

สมมติ `Reg[rs]=7` และ `Reg[rt]=7` เราสั่ง ALU ให้ลบ `7−7` ได้ `Zero=1` จึงใช้ `PCWriteCond` อนุญาตให้ PC รับ Branch Target=`1016` จาก ALUOut ของ Step 1

<div className="mc-step-card">
  <div className="mc-step-heading"><strong>วงจรย่อจากรูปที่ 2 ของข้อสอบ</strong><span>Step 2/2 · State 2</span></div>
  <div className="mc-step-recap"><code>ALU ตรวจ Zero / ALUOut ส่ง Branch Target ไป PC</code><span>Reg[rs] 7 · Reg[rt] 7 · ALU: 7−7=0 · Zero=1 · PCWriteCond · ALUOut 1016 · PCSource 01 · PC 1016</span></div>
  <div className="mc-data-operation"><small>DATA Operation · โจทย์ให้มาแล้ว</small><code>if (A == B) PC ← ALUOut</code><span>ตัวอย่าง: 7 − 7 = 0 → Zero=1 → PC ← 1016</span></div>
  <div className="mc-control-zones">
    <div><h4>1. เลือกทาง</h4><ul><li><code>ALUSrcA = 1</code> เลือก Register ตัวแรก</li><li><code>ALUSrcB = 00</code> เลือก Register ตัวที่สอง</li><li><code>ALUOp = 01</code> ลบเพื่อตรวจว่าเท่ากัน</li><li><code>PCSource = 01</code> เลือก Branch Target จาก ALUOut</li></ul></div>
    <div><h4>2. เปิดใช้งาน</h4><ul><li><code>PCWriteCond = 1</code> เขียน PC เฉพาะเมื่อ Zero=1</li></ul></div>
  </div>
  <p className="mc-step-note">ผลลบของ ALU ใช้ตรวจ Zero ส่วน Address ที่จะ Branch มาจาก ALUOut ไม่ใช่ผลลบนั้น</p>
  <div className="mc-step-footer">จบบท 5: beq • Branch if Equal <span>บทถัดไป: j • Jump</span></div>
</div>

</section>

<section className="lesson-section" id="ch3-jump">

## บท 6/6: เปลี่ยน PC โดยไม่มีเงื่อนไข

### `j` • Jump

**เป้าหมาย:** `PC ← Jump Address`

### Step 1/1: สร้าง Jump Address แล้วเขียน PC

**State 1 → Next State 0**

Jump ไม่ต้องเปรียบเทียบ Register และไม่ต้องใช้ ALU คำนวณ Target ในรูปนี้ CPU นำ `IR[25:0]` Shift left 2 แล้วประกอบกับ `PC[31:28]` ก่อนเลือก Jump Address ไปเขียน PC

<div className="mc-step-card">
  <div className="mc-step-heading"><strong>วงจรย่อจากรูปที่ 2 ของข้อสอบ</strong><span>Step 1/1 · State 1</span></div>
  <div className="mc-step-recap"><code>PC[31:28] + IR[25:0] + 00 → Jump Address → PC</code><span>IR[25:0] 26 bits · PC[31:28] 4 bits · Shift left 2 · Join bits · PCSource 10</span></div>
  <div className="mc-data-operation"><small>DATA Operation · โจทย์ให้มาแล้ว</small><code>{'PC ← {PC[31:28], IR[25:0], 00}'}</code><span>Jump เสร็จใน State 1 แล้วกลับ State 0 ทันที</span></div>
  <div className="mc-control-zones">
    <div><h4>1. เลือกทาง</h4><ul><li><code>PCSource = 10</code> เลือกช่อง 2 ซึ่งเป็น Jump Address</li></ul></div>
    <div><h4>2. เปิดใช้งาน</h4><ul><li><code>PCWrite = 1</code> อนุญาตให้เปลี่ยน PC</li></ul></div>
  </div>
  <p className="mc-step-note">j ไม่มี State 2 เพราะเปลี่ยน PC ได้ตั้งแต่ State 1</p>
  <div className="mc-step-footer">จบบท 6: j • Jump <span>ครบทุกคำสั่งแล้ว ต่อไปนำ CONTROL ไปกรอกตารางที่ 4</span></div>
</div>

</section>

## สรุปข้อสอบ: กรอกตารางที่ 3 และ 4

เมื่อทำครบทั้ง 6 บทแล้ว ให้ดึงค่า CONTROL จากสองโซนในแต่ละ Step มาใส่ตารางที่ 4 ตาม Opcode และ State

### ตารางที่ 3: DATA ที่ต้องเติม

สำหรับ `sw` ใน Step 2 โจทย์เว้น DATA Operation ไว้ ให้ตอบว่า:

<div className="mc-summary-data"><small>Store Word • State 2</small><code>Mem[ALUOut] ← Reg[IR[20:16]]</code><span>CONTROL: IorD=1, MemWrite=1</span></div>

### ตารางที่ 4: Main Control

ตารางนี้แสดงเฉพาะ Signal ที่มีค่าไม่เป็นศูนย์ ช่องอื่นให้กรอก `0` หรือ `00` ตามขนาด Signal ตามข้อกำหนดในโจทย์

<div className="table-scroll">

|---:|---|---|---|---:|
| 0 | `xxxxxx` | `ALUSrcB=01` | `PCWrite=1, MemRead=1, IRWrite=1` | 1 |
| 1 | `000000` R-type | `ALUSrcA=1, ALUOp=10` | ไม่มี | 2 |
| 1 | `000010` j | `PCSource=10` | `PCWrite=1` | 0 |
| 1 | `000100` beq | `ALUSrcB=11` | ไม่มี | 2 |
| 1 | `100011` lw | `ALUSrcA=1, ALUSrcB=10` | ไม่มี | 2 |
| 1 | `101011` sw | `ALUSrcA=1, ALUSrcB=10` | ไม่มี | 2 |
| 2 | `000000` R-type | `RegDst=1` | `RegWrite=1` | 0 |
| 2 | `000100` beq | `ALUSrcA=1, ALUOp=01, PCSource=01` | `PCWriteCond=1` | 0 |
